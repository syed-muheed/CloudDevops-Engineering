2. What this means
Your Legacy Payment service connects directly to AlloyDB using its private IP.

AlloyDB requires SSL encryption, so the database connection must be encrypted.

However, the application code currently contains:
ssl: {
  require: isProduction,
  rejectUnauthorized: false
}


There are two separate considerations:
- Encryption: AlloyDB requires an encrypted connection.
- Certificate verification: The Node.js application explicitly disables verification of the database server certificate.
Therefore, enabling global TLS verification will not automatically resolve the database-specific certificate verification issue.
